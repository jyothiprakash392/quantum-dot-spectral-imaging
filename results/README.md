# Results index

Result files are kept inside the project that generated them so scripts can retain their original relative paths. The folders below contain the main evidence sets:

- `QD_Converter_Documented_Results.xlsx`: the supplied consolidated results workbook.

- `projects/01-VirtualQuantumDotAgent/`: original virtual-agent demo and validation workspaces, plots, reference curves, and material-calibration reports.
- `projects/02-QDUpconversionCCDSpectrometer/`: SWIR-to-visible demo spectra, CCD/reconstruction figures, validation outputs, and model-comparison tables.
- `projects/03-QDVoltageSelectedDualConverter/results/`: dual-converter figures, tables, and generated architecture/model diagrams.
- `archive/QDVoltageTunableDualConverter-legacy-20260908/`: evidence retained with the earlier integrated package snapshot.

MAT files are MATLAB workspaces/results, CSV files are spectra or tabular comparisons, PNG files are plots/diagrams, and TXT/MD/JSON files summarize validation, provenance, model settings, or reproducibility. These are supplied historical outputs, not newly generated results from this repository assembly.
