# Archived project snapshot

`QDVoltageTunableDualConverter-legacy-20260908/` preserves an earlier integrated MATLAB/Simulink package and its original evidence. It is separated from the three current packages because some implementations and result reports differ from the current versions.

The archived scripts can depend on archived versions of shared functions. Open and run this snapshot from its own folder so MATLAB does not resolve functions from a newer project package by accident. The active combined implementation is in `../projects/03-QDVoltageSelectedDualConverter/`.

The main code guide covers the distinct current MATLAB sources; [`../docs/LEGACY_MATLAB_FILE_INDEX.md`](../docs/LEGACY_MATLAB_FILE_INDEX.md) covers the additional legacy MATLAB files.

The separately supplied `outputs/QDVoltageTunableDualConverter/QDDualConversionSystem.slx` copy was 0 bytes, so it was not added as a model. Non-empty model files from the active packages and archived snapshot are included.
